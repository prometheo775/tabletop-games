# Immagini e Documenti Storici di Riferimento (Caccia alla Repubblica)

In questa cartella vanno inserite le immagini di riferimento storiche (es. scansioni di proclami, foto di documenti d'epoca, particolari di sigilli, stampe d'epoca) utilizzate per ricostruire gli asset vettoriali SVG per le carte del gioco.

## Come utilizzare questa cartella:
- Inserisci qui i file d'immagine (PNG, JPG, SVG) di documenti d'epoca reali.
- L'agente AI (utilizzando la skill `svg-card-reference`) analizzerà visivamente questi file per estrarre dettagli stilistici (fregi, cornici, palette colori, sigilli) e ricreare corrispondenti componenti SVG puliti e pronti da essere montati come layer nelle carte.
